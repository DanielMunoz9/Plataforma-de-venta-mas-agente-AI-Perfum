# Vane France Brand Assets

This directory contains the brand assets for the Vane France theme:

## Asset Files

- **logo.png** - Vane France logo on black background (from image3)
- **storefront.jpg** - Storefront photo (from image4)
- **product-1.jpg** - Product shot on beige background (from image2)
- **product-2.jpg** - Product shot on black background (from image1)

## Usage

These assets are automatically used by the theme in various locations:

- Logo: Used in header and as default custom logo
- Storefront: Used as default hero background image
- Product images: Used as placeholder/demo images in catalogs

## File Requirements

- **Logo**: PNG format, transparent background preferred
- **Storefront**: JPG format, minimum 1200px width
- **Product images**: JPG format, square ratio preferred (500x500px minimum)

## Installation

When the theme is activated, these assets are available at:
`wp-content/themes/vane-france-theme/assets/img/`

The theme automatically detects and uses these files for enhanced visual presentation.
